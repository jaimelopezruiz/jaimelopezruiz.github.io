1Abstract

My final-year project develops autonomous control of cochlear implant electrode array insertion using bipolar impedance sensing, on an existing insertion robot at the Hamlyn Centre for Robotics, supervised by Prof Ferdinando Rodriguez y Baena.

2Scope

The robot and its control already exist. The project covers three things: collecting insertion data, developing a control algorithm that uses bipolar impedance as feedback, and integrating that algorithm on the robot.
